# Changelog

## 1.0.0

- First public BetterFreeCam release, derived from Bananegame FreeCAM 0.0.2 as an independent source reimplementation.
- Direct main-camera movement and raw mouse look, with immediate start and stop.
- Bypass the native cinematic camera's movement inertia, look drift, shake and depth-of-field path.
- Preserve the F3/ESC, WASD, vertical movement, Shift, HUD and field-of-view controls.
- Restore prior camera, input, HUD, cursor and field-of-view states when leaving freecam or changing scenes.
- Use a separate BetterFreeCam plugin GUID and configuration file.

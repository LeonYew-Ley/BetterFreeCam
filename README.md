# BetterFreeCam

A free camera for **PEAK** with instant movement and no camera inertia.

**Press F3 to start. Press Esc or F3 to return to your character.**

## Controls

| Key | Action |
| --- | --- |
| **F3** | Turn freecam on / off |
| **Esc** | Exit freecam |
| W / A / S / D | Move the camera |
| Mouse | Look around |
| Space / Left Ctrl | Move up / down |
| Left Shift | Move faster |
| Mouse wheel | Zoom in / out |
| H | Show / hide the game interface |

These are the default controls. Works in the Airport and during a run.

## Install

1. Install BetterFreeCam with Gale or another Thunderstore mod manager. Requires [BepInExPack for PEAK](https://thunderstore.io/c/peak/p/BepInEx/BepInExPack_PEAK/).
2. Disable the original **FreeCAM** or any older FreeCAM fix, then launch the modded game.

Only you need this mod. Your character stays in the world and can still take damage while you move the camera.
